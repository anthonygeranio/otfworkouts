# Notes for the App Review team (paste into "App Review Information → Notes")

```
OTF Workouts is an independent, unofficial reader for the public r/orangetheory
subreddit's daily workout thread. It is not affiliated with Orangetheory Fitness
or Reddit, and it states this in the app and in the description.

How it works:
- A backend server reads Reddit's PUBLIC RSS feeds (reddit.com/.../.rss) for the
  r/orangetheory daily thread, formats the community-posted workout, and serves
  it to the app. Every workout credits the Reddit author and links to the source.
- No login is required to use the app. There is no account system.

Notifications (optional):
- Reviewers can test the app fully without enabling notifications.
- If enabled, the app registers an anonymous push token + time zone with our
  server to deliver one alert per day when the workout is posted. This is opt-in.

Data & privacy:
- No ads, no analytics, no tracking. See privacy policy:
  https://anthonygeranio.github.io/otfworkouts/privacy.html

Trademark:
- "Orangetheory"/"OTF" are used descriptively to identify the community whose
  public posts are displayed. The app is clearly labeled unofficial.

No demo account is needed. Content updates daily; if the community has not yet
posted a given day's workout, the app shows an empty state with an explanation.
```
